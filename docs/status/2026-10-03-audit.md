## Confirmed in the starting code

- `KartAI._press()` writes global Input actions; every `Kart` reads those actions.
  Opponents can steer, accelerate, brake and stop the human player's kart.
- `KartAI._advance_cursor()` truncates fractional per-frame progress to an integer;
  at ordinary speeds and 60 Hz it does not advance the racing-line cursor.
- `RaceMain._build_field()` creates the player's mode handling resource but never
  assigns it. AI handling is assigned after the kart enters the scene tree.
- `RaceMain._build_ui()` creates `RaceHud` without binding a kart or director.
- Grid orientation uses Godot's -Z-facing `look_at`, while kart propulsion uses +Z.
- `Kart._apply_steering()` multiplies world velocity by the complete new basis
  rather than the yaw delta. Existing heading can be applied a second time.
- `test_race_integration.gd` edits `director._state` directly to "test" a lap;
  this does not exercise checkpoint collision, valid lap transitions or finishing.
- `export_presets.cfg` uses the original vendor's namespace, no explicit SDK
  targets, no launcher artwork and no release AAB preset.
- Art/audio are explicitly absent from the running scene. The recovered data
  and placeholder track mesh do not establish a finished visual/audio port.

These are code-inspection findings, not yet claims of repaired or device-tested
behavior. Historical README build/test claims have not been reproduced by this
execution session.

## First increment: trustworthy execution evidence

`scripts/checked_process.py` rejects nonzero exits, timeouts, Godot error logs
(including ANSI-colored errors), failed check summaries and missing required test
completion markers. Its stdlib unit tests simulate each failure, including an
error that returns exit code zero. `runtime-evidence` runs every Godot test and
retains raw logs, the exact source revision, source archive, engine archive and
checksums for offline reproduction. It does not fetch or publish the DMG, signing
keys or proprietary extracted media.

The working container initially had JDK 21, Kotlin, CMake and Ninja, but no Godot,
Android SDK, ADB or accessible outbound network. GitHub's connected API works.
The evidence artifact provides a reproducible route to run the pinned engine in
that container rather than pretending local tools were installed.
